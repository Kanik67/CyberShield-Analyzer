🛡️ CyberShield Analyzer

A beginner-friendly cybersecurity learning tool for password analysis, entropy, hashing, and cryptographic security concepts.

📌 Project Overview

CyberShield Analyzer is a browser-based cybersecurity project created as a BCA student project. It helps users understand basic password security and cryptography through simple interactive tools.

The project focuses on learning and demonstration rather than professional security auditing.

🚀 Key Features

🔐 Password strength and security analysis

📊 Shannon entropy and security metrics

🔎 Pattern and common-password checks

⏱️ Educational brute-force/crack-time estimation

#️⃣ Cryptographic hash generation and comparison

🔑 Secure key and value generation

🛡️ Security recommendations and educational information

💻 Local/browser-based security processing

🛠️ Technologies

React

TypeScript

JavaScript

HTML5

CSS3

Vite

Web Crypto / browser cryptographic APIs

🔄 How It Works

The user enters a value into a selected security tool.

CyberShield analyzes the input in the browser.

Security metrics and results are calculated.

The application displays the results in an easy-to-understand interface.

Educational recommendations help explain the security concepts.

⚠️ Limitations

CyberShield Analyzer is an educational student project. Security scores and crack-time estimates are simplified estimates and should not be treated as professional security assessments.

Users should not enter real passwords, API keys, private keys, or other sensitive information into an educational tool.
